# Changelog

All changes are listed by requirement identifier with the reason. Identifiers are stable across versions.

## 0.1 draft 2 (2026-10-06)

- Deposited on Zenodo: DOI 10.5281/zenodo.23179115 (PDF, evidence record schema, example record).

- **G-6** reworded after gate review. Vendor-specific seals, readers, cameras, and software are permitted for any check, provided the procedure defines a fallback for the case where the device returns no result, is not fitted, or meets a seal or vehicle it cannot read, and the fallback writes to the same evidence record. The previous wording would have excluded the common RFID-reader-plus-yard-agent pattern, which conforms.
- **P-5** note added on current feasibility: the requirement sits at Full because most facilities cannot meet it today, although it has run at scale in one national network since 2025 and is the reason the reference implementation is open.
- **Section 5.3** open question added on drop-and-hook at unattended yards.
- Document renamed from working title to Freight Custody Verification Framework (FCVF).

## 0.1 draft 1 (2026-10-05)

- First draft. 48 requirements (G-1 to G-6, P-1 to P-14, S-1 to S-7, D-1 to D-5, E-1 to E-4, V-1 to V-5, R-11 to R-12, C-1 to C-3), ten risk rules (R-1 to R-10), evidence record (24 fields), three conformance levels, mapping to existing guidance, reference implementation section, self-assessment checklist.
